## Build & test (Xcode)
- **Open `app/GINEXUS.xcodeproj`, pick the `GINEXUS` scheme, ⌘R.** The project is **generated by
  XcodeGen** from `app/project.yml` — never hand-edit the `.xcodeproj`; change `project.yml` then run
  `xcodegen generate` in `app/`. (`Package.swift` stays the source of truth for `GinexusCore` + tests.)
- **How the Rust core is embedded (sandbox-proof — do NOT revert to a Run Script that runs `cargo`):**
  1. The **`GINEXUS` scheme's build pre-action** runs `cargo build --release -p ginexus-server` and
     stages it to `app/artifacts/`. Scheme pre-actions run **outside** Xcode's per-Run-Script sandbox
     (`/usr/bin/sandbox-exec`), so cargo can read the sibling `../core` tree **regardless of
     `ENABLE_USER_SCRIPT_SANDBOXING`**. A Run Script phase running cargo gets sandboxed by the GUI and
     fails with `Could not locate working directory: Operation not permitted (os error 1)` — that bug
     is why cargo lives in the pre-action. (`xcodebuild -scheme` runs pre-actions too; `-target` does NOT.)
  2. A native **Copy Files phase** embeds `artifacts/ginexus-server` into `Contents/MacOS` with
     **Code Sign On Copy**, so Xcode signs the nested binary itself — **no `codesign --deep`**. The app's
     `CODE_SIGN_ENTITLEMENTS` attach only to the Swift app (correct: TCC calls originate in the app,
     never the sidecar). When SP5 adds EventKit grants, keep them on the app, not the core.
  3. A guard **pre-build script** fails the build loudly if the staged core is missing (Xcode swallows
     pre-action failures) — it only reads a path under `$SRCROOT`, so it stays sandbox-safe.
- **Canonical shippable build = `app/scripts/build_app.sh`** (Terminal, never sandboxed): Developer-ID
  per-Mach-O sign + notarize (no `--deep`). ⌘R is for fast iteration; `build_app.sh` is the artifact.
- Verified: clean build + a build with `ENABLE_USER_SCRIPT_SANDBOXING=YES` both SUCCEED and produce a
  strict-valid app + nested core; on launch the app spawns the core over the UDS at
  `~/Library/Application Support/GINEXUS/run/ginexus.sock` (`GET /healthz` → `{"status":"ready"}`).
  The server unlinks a stale socket before bind; if `open` ever reactivates a lingering instance with a
  dead core, fully quit it (⌘Q) and relaunch — Xcode ⌘R always launches fresh.
